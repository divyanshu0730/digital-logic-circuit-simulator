# Digital Logic Circuit Simulator Pro

A C-based Digital Logic Circuit Simulator designed to simulate digital logic gates, generate truth tables, evaluate Boolean expressions, and analyze digital logic circuits.

## 🚀 Features

- AND, OR, NOT, NAND, NOR, XOR and XNOR gate simulation
- Truth table generation
- Boolean expression evaluation
- Boolean expression truth tables
- Multi-gate circuit simulation
- Boolean expression analysis
- Input validation
- Save and load Boolean expressions
- Save and load circuit configurations
- Project statistics
- Menu-driven user interface

## 🛠️ Technology Used

- Standard C Library
- Digital Electronics
- Boolean Logic

## ▶️ How to Run

1. Download or clone this repository.
2. Open the C source file in a C compiler.
3. Compile the program.
4. Run the executable.
5. Select an option from the main menu.

## 🎯 Project Purpose

The purpose of this project is to combine C programming concepts with Digital Electronics concepts and provide an interactive environment for understanding and testing logic circuits.
